A minimal and evolving template for creating Vulkan applications using Zig.

This project is designed to provide a clean starting point for Vulkan development without unnecessary abstractions, making it easy to understand, refactor, and extend.
This is not a framework and does not try to be one.
It is a starting point.

## Dependencies

- Zig (0.15.1)
- Vulkan SDK
- SDL3
- Vulkan Memory Allocator (VMA)

Only the Vulkan SDK should be setup with VULKAN_SDK environment variable set to its location.
